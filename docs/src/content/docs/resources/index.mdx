Regardless of their expertise, we want to provide information to make sure users are well-positioned to use
harpy successfully. To that end, we provide various guides, extra details about snakemake, running harpy
on an HPC (computer cluster), etc. If you have idea to contribute, consider beginning a
[discussion](https://github.com/BLinkseq/harpy/discussions) to flesh out ideas.
